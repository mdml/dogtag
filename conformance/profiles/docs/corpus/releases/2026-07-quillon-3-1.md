# Quillon 3.1

Released 2026-07-14. Current. Artefacts are at
[the download index](https://packages.quillon.example/stable/3.1).

## Removed: the sidecar protocol

A 2.x collector cannot connect. This was deprecated in
[3.0](releases/2026-05-quillon-3-0.md) and the reasoning is in
[decisions/0002-drop-the-agent-sidecar.md](decisions/0002-drop-the-agent-sidecar.md). If any
collector in the fleet is still on 2.x, do not upgrade the gateway yet.

## Compaction no longer blocks the writer

The compactor's replacement segment is written on its own file handle, so a compaction pass no
longer contends with the append path. In practice this halves the queue-depth spike that used to
mark every cycle. [compaction](internals/ledger/compaction.md) describes the cycle as it now
runs.

## Documentation: two limits pages

What a deployment carries and what a caller is allowed used to be one page and were never the
same subject. They are now [reference/limits.md](reference/limits.md) and
[reference/api/v2/limits.md](reference/api/v2/limits.md); links to the old anchors will not
resolve.

## Upgrade notes

No ledger change, no envelope change — the schema is frozen for 3.x by
[decisions/0003-freeze-the-envelope-schema.md](decisions/0003-freeze-the-envelope-schema.md).
Follow [upgrading](guides/upgrading.md), and upgrade collectors last.

For where everything else lives, start at [the top-level README](README.md).
