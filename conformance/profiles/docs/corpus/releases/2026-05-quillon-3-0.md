# Quillon 3.0

Released 2026-05-06. The last version that accepts the sidecar protocol.

## Durable acknowledgements

An acknowledgement now means the envelope is on disk. Previously it meant the envelope had been
accepted into the queue, which was true and unhelpful. Collectors that were already holding
unacknowledged envelopes need no change; ones that were not now have a reason to.

## Explicit backpressure

Refusals carry `ingest.backpressure` and a retry hint instead of a bare connection stall. The
operator-facing half is [backpressure](backpressure); the caller-facing half is in
[streaming-ingest.md](guides/integration/streaming-ingest.md).

## Deprecated: the sidecar protocol

Still accepted, with a warning per connection. It goes away in 3.1 — see
[decisions/0002-drop-the-agent-sidecar.md](decisions/0002-drop-the-agent-sidecar.md) and plan the
collector rollout now rather than during the 3.1 upgrade.

## Upgrade notes

No ledger change. Configuration gained `[accept] clock_skew`, defaulted to the value 2.9
hard-coded, so an unchanged file behaves identically. Full procedure in
[upgrading](guides/upgrading.md).
